
# Data Requirements

Milestone 1 of the Physics Learning Platform shall manage the following categories of data:

## User Data

The system shall store information required to identify and authenticate users.

### Student Data

- Full name
- Username  
- Password  
- Optional email address  
- Optional mobile phone number  
- User role  
- Account creation date

### Teacher Data

- Full name
- School name  
- Email address  
- Mobile phone number  
- Password  
- Verification method  
- Verification status  
- User role  
- Account creation date  

## Educational Classification Data

The system shall store information used to organize Physics content.

- Educational level
- Module
- Physics topic  

## Question Data

The system shall store the information required to display and evaluate multiple-choice questions.

- Question text (Which may include mathematical equations and expressions) 
- Answer options (Which may include mathematical equations and expressions)
- Correct answer (Which may include mathematical equations and expressions)  
- Educational level
- Module
- Physics topic   
- Mathematical expressions  
- Diagrams or images  
- Tables, where applicable  

## Assessment Data

The system shall process information required to generate teacher assessments.

- Selected educational level
- Selected Modules 
- Selected Physics topics
- Requested number of questions  
- Selected questions  
- Assessment answer key  

Long-term storage of generated assessments is not required in Milestone 1.

## Worksheet Data

The system shall store information required to organize and download PDF worksheets.

- Worksheet title  
- Educational level
- Module 
- Physics topic
- PDF file location  
- Worksheet preview, where available  

## Practice Session Data

The system shall temporarily process information during a student or teacher practice session.

- Selected educational level
- Selected modules  
- Selected Physics topics  
- Questions presented  
- Answers submitted  
- Correct and incorrect responses  
- Current score  
- Final percentage score 

Long-term storage of practice-session history is not required in Milestone 1.

## Feedback Data

The system shall store information submitted through the feedback feature.

- User identifier  
- User role  
- Feedback category  
- Feedback description  
- Date and time of submission
