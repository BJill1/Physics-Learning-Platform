# System Design Plan

**Project:** Physics Learning Platform  
**Milestone:** Milestone 1 – Physics Assessment Platform

## Purpose

This document outlines the system design activities for Milestone 1. The objective is to transform the approved software requirements into a detailed design that will guide implementation.

---

## 1. High-Level System Architecture

**Status:** ✅ Completed

Design the overall architecture of the system, showing the major software components and how they interact.

---

## 2. Use Case Diagram

**Status:** ⏳ Not Started

Create a UML Use Case Diagram illustrating the interactions between users and the system.

---

## 3. Activity Diagrams

**Status:** ⏳ Not Started

Create UML Activity Diagrams to describe the workflows of the major system processes.

---

## 4. Sequence Diagrams

**Status:** ⏳ Not Started

Create UML Sequence Diagrams showing the interactions between system components during the execution of major use cases.

---

## 5. Class Diagram

**Status:** ⏳ Not Started

Design the UML Class Diagram showing the major classes, their attributes, methods, and relationships.

---

## 6. Database ER Diagram

**Status:** ⏳ Not Started

Design the Entity-Relationship Diagram (ERD) representing the database entities and their relationships.
