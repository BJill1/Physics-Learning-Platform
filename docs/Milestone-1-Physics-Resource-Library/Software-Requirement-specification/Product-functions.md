# Product Functions

### The first milestone of the Physics Learning Platform provides the following core functions:

- Register and authenticate teachers and students.
- Control access to platform features using teacher and student roles.
- Generate Physics multiple-choice assessments from a curated question bank based on the selected educational level, topic, and number of questions.
- Allow teachers to preview, print, or download generated multiple-choice assessments together with their answer keys.
- Provide teachers with read-only access to PDF worksheets organized by educational level and topic.
- Allow teachers to browse, preview, and download worksheets without modifying the original resources.
- Allow students to select an educational level and topic for practice.
- Present multiple-choice questions to students one at a time.
- Provide immediate feedback after each student response.
- Display a final score and performance summary at the end of each student practice session.
- Provide search and navigation features to help users locate questions and worksheets.
