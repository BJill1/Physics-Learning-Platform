# 1.1 Product Functions

### The first milestone of the Physics Learning Platform provides the following core functions:

- Register and authenticate teachers and students.
- Control access to platform features using teacher and student roles.
- Generate Physics multiple-choice assessments from a curated question bank based on the selected educational level, topic, and number of questions.
- Allow teachers to preview, print, or download generated multiple-choice assessments together with their answer keys.
- Provide teachers with read-only access to PDF worksheets organized by educational level and topic.
- Allow teachers to browse, preview, and download worksheets without modifying the original resources.
- Allow students to select an educational level and topic for practice.
- Present multiple-choice questions to students one at a time.
- Provide immediate feedback after each student response.
- Display a final score and performance summary at the end of each student practice session.
- Provide search and navigation features to help users locate questions and worksheets.

# 1.2 User Classes

The first milestone of the Physics Learning Platform supports the following user classes:

### Teacher

Teachers use the platform to generate Physics multiple-choice assessments from the question bank, 
preview assessments, print or download assessments with answer keys, browse downloadable PDF worksheets, 
and search for educational resources.

### Student

Students use the platform to practise Physics multiple-choice questions by selecting an educational level and topic. 
The platform presents questions one at a time, provides immediate feedback after each response, and displays a performance 
summary at the end of each practice session.

# 1.3 Operating Environment

The first milestone of the Physics Learning Platform shall operate in the following environment:

- The platform shall be accessible through modern web browsers.
- The platform shall support desktop and laptop computers for both teachers and students.
- The platform shall support commonly used mobile web browsers to enable students and teachers to access learning resources on smartphones and tablets.
- The platform shall require an active internet connection.
- The platform shall be deployed as a web-based application and be accessible through a public web address.

# 1.4 Constraints

The first milestone of the Physics Learning Platform shall be developed under the following constraints:

- The platform shall be developed as a web-based application.
- Only registered teachers and students shall have access to protected platform features (Free registration).
- Teachers shall have read-only access to the question bank and worksheet library.
- Students shall only access the student practice features assigned to this milestone.
- Physics questions and worksheets shall be limited to the content available in the curated question bank and worksheet library.

# 1.5 Assumptions and Dependencies

The first milestone of the Physics Learning Platform is based on the following assumptions and dependencies:

- Users have access to a stable internet connection.
- Users have access to a supported web browser on a desktop, laptop, tablet, or smartphone.
- A curated Physics question bank and worksheet library are available before the platform is deployed.
- Users have basic computer and web navigation skills.
- Teachers are responsible for selecting appropriate questions and worksheets for their students.
- Students are responsible for completing practice sessions independently.
- The platform depends on a reliable hosting environment to provide continuous access to users.
